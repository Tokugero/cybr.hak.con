L1 context file. For the ultra-concise project map, read `.abstract.md` (L0) first. Subsystems each have their own `.overview.md` for deeper detail.

## What this project is

A local RAG tool that ingests the HackTricks GitHub repository into a Qdrant vector store and exposes search as an MCP tool. The LLM harness loads the MCP server directly; there is no HTTP API or user-facing CLI. When the agent needs to understand a tool or technique, it calls the MCP search tool and gets back ranked HackTricks chunks.

## Dev workflow

```sh
# Start local services (Qdrant + Ollama)
docker compose up -d

# Ingest HackTricks (one-time setup)
uv run python -m lib.ingest

# Run tests (separate commands — conftest collision at workspace root)
cd lib && uv run pytest
cd mcp && uv run pytest

# Load MCP server in harness
# Configure harness to run: uv run python -m mcp.server
```

## Storage / persistence

| Store | Location | Contents |
|-------|----------|----------|
| Qdrant collection | Docker volume `qdrant_data` | HackTricks chunk embeddings |
| Ollama models | Docker volume `ollama-data` | nomic-embed-text model weights |
| HackTricks source | Cloned repo on host | Raw markdown; not committed |

## Non-negotiables

- Never commit unencrypted secrets
- Never use floating/latest dependency versions — pin everything in `pyproject.toml`
- HackTricks source repo is local only; never commit it or its content
