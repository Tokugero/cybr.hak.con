# .overview.md — mcp

L1 subsystem context. Components, exports, dependencies, dev workflow.

## What this subsystem does
FastMCP server that wraps the library subsystem and exposes a single search tool via the Model Context Protocol. Loaded locally by the LLM harness (stdio transport); no HTTP exposure.

## Component table
| Path | Type | Purpose | Exports | Deps |
|------|------|---------|---------|------|
| `src/mcp_server/__init__.py` | package | Public re-exports | `mcp` | — |
| `src/mcp_server/__main__.py` | entrypoint | `python -m mcp_server` target; calls `main()` | — | server |
| `src/mcp_server/server.py` | server | FastMCP app, search tool, env-based wiring | `mcp`, `search`, `main` | fastmcp, rag-lib |
| `src/mcp_server/schemas.py` | models | MCP search response DTOs | `SearchResultDTO`, `SearchResponse` | pydantic |

## Dependencies on other subsystems
Depends on `lib/` for embedding and Qdrant search.
