# .overview.md — lib

L1 subsystem context. Components, exports, dependencies, dev workflow.

## What this subsystem does
Ingestion pipeline: reads the HackTricks repository, chunks markdown into passages, embeds them via Ollama (nomic-embed-text), and stores them in Qdrant. Also exposes search: takes a query string, embeds it, and returns ranked chunks from Qdrant.

## Dependencies on other subsystems
None — the library subsystem is the foundation; `mcp/` depends on it.

## Dev workflow
```sh
# Ingest HackTricks (one-time setup)
uv run python -m lib.ingest

# Run tests
uv run pytest lib/
```

## Test commands
```sh
uv run pytest lib/
uv run pytest lib/ --cov
```

**Shape mix:** unit (models, chunker, embedder), contract (store against in-memory Qdrant fake), integration (search and ingest pipelines, mocked at external boundary). End-to-end wired in step 06.
